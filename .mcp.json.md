# Project MCP Servers for KPZ

## Overview

This file configures project-scoped MCP (Model Context Protocol) servers for the Kitaplatz-Zentrale project. These servers provide enhanced tooling for all developers without requiring credential setup.

## Configured Servers

### 1. Terraform (HashiCorp Official)

**Purpose:** Terraform registry access, module/provider documentation, infrastructure development

**Why relevant to KPZ:**
- Essential for working with `terraform/` infrastructure code
- Provides module search, provider documentation, and best practices
- Already proven in environment (Docker-based)

**Prerequisites:** Docker (already required for KPZ development)

**Credentials:** None required (TFE token optional for HCP Terraform features)

**Package:** `hashicorp/terraform-mcp-server` (Docker image)

### 2. Context7 (Upstash)

**Purpose:** Live, up-to-date documentation for npm packages and frameworks

**Why relevant to KPZ:**
- Backend: Express, Mongoose, TypeScript, AWS SDK
- Frontend: React 18, Material-UI (Joy), React Router
- Testing: Jest
- Build: Vite

**Prerequisites:** Node.js/npm (already in project)

**Credentials:** None required (works with rate limits; API key optional for higher limits)

**Package:** `@upstash/context7-mcp`

### 3. AWS Documentation (AWS Labs)

**Purpose:** AWS service documentation and best practices

**Why relevant to KPZ:**
- Lambda functions (backend, email, notification, scraper, location-service)
- S3/CloudFront (frontend hosting)
- API Gateway, ACM, EventBridge, CloudWatch
- SES, SNS (email/notifications)

**Prerequisites:** Python 3.x with uvx

**Installation if missing:**
```bash
pip install uvx
# or
brew install uvx  # macOS with Homebrew
```

**Credentials:** None required

**Package:** `awslabs.aws-documentation-mcp-server`

## Prerequisites

All developers need:
- ✅ **Docker** - Required for Terraform server (already needed for KPZ)
- ✅ **Node.js/npm** - Required for Context7 (already in project)
- ⚠️ **Python 3.x with uvx** - Optional, for AWS documentation server

## Optional Enhancements

Team members can enhance servers at user/local scope:

**Context7 with API key** (higher rate limits):
```bash
# Add API key to user scope
export CONTEXT7_API_KEY="your-key"
```

**Terraform with HCP Terraform** (workspace management):
```bash
# Add TFE token to user scope
export TFE_TOKEN="your-token"
```

## Why These Servers?

### ✅ Included
- **terraform** - Core infrastructure development tool
- **context7** - Zero-friction library docs for entire tech stack
- **aws-documentation** - AWS is fundamental to KPZ architecture

### ❌ Not Included

**aws-terraform (AWS Labs)** - Deprecated as of February 2026
- AWS Labs officially directs users to HashiCorp's terraform server
- No longer maintained
- HashiCorp server provides all registry features

## Verification

After pulling the repo, verify servers are available:

```bash
# Check Docker
docker pull hashicorp/terraform-mcp-server

# Check npm
npx -y @upstash/context7-mcp --version

# Check Python/uvx (optional)
uvx --version
```

## Team Migration

### If you have existing MCP plugins

Team members with context7 or other plugins enabled in `~/.claude/settings.json`:
- Plugins take precedence over project-scoped configs
- Can disable plugins to use project-scoped servers
- Project-scoped servers activate automatically when plugins are disabled

### Benefits of project scope

- Consistent tooling across team
- No credential setup for basic features
- Auto-loads when opening KPZ project
- Safely committed to version control
